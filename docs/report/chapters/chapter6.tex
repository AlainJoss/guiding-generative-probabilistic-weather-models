\chapter{Evaluation framework}

To evaluate the performance of our guidance algorithm we need to test the two requirements we have set for it. 
1. The guidance algorithm should be able to generate weather states that are consistent with the target trajectory (extreme as prescribed).
2. The guided states should be coherent across following dimensions:
- temporally (transitions across the same variable should be smooth)
- spatially (region of interest)
- vertically (pressure levels)
- across variables (patterns should be coherent to the learned weather transition function)

To help us evaluate its performance more generally, we also analyze the algorithm under different settings at flow time.
